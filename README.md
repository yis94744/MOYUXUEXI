# MOYUXUEXI — 游戏开发知识库

按技术栈分类的学习文档集合。全部内容为**纯静态 HTML / Markdown**，克隆后用浏览器直接打开即可阅读，不需要构建步骤，也不依赖外部 CDN。

---

## 分类结构

```
MOYUXUEXI/
├── unity/         C# + Unity 路线（30 页站点 + 完整知识手册）
├── unreal/        C++ + Unreal 路线（28 页）
├── lua/           Lua 热更新路线（26 页）
├── algorithms/    游戏算法与系统设计（35 页）
└── svn/           SVN 版本控制教程（3 套）
```

每个路线目录里都有 `index.html`（路线总览）和 `kp-index.html`（知识点索引，168 个知识点）。

## 使用方式

### 在线阅读

```bash
git clone https://github.com/yis94744/MOYUXUEXI.git
cd MOYUXUEXI
```

然后用浏览器打开任意分类的入口：

| 分类 | 打开 |
| --- | --- |
| Unity | `unity/index.html` |
| Unreal | `unreal/index.html` |
| Lua | `lua/index.html` |
| 算法 | `algorithms/index.html` |
| SVN | `svn/tutorial/index.html` 或 `svn/gui-tutorial/index.html` |

### 本地静态服务器（可选）

如果浏览器对本地文件的脚本有安全限制：

```bash
python -m http.server 8000
# 访问 http://localhost:8000/unity/
```

## 知识点索引与跨分类跳转

四个技术路线（unity / unreal / lua / algorithms）共享一套**168 个知识点**的索引体系：

- 每页顶部的「**读这一页之前，建议先掌握**」区块会链接到前置知识点

- `kp-index.html` 是完整索引，**支持跨分类跳转**（例如在 Lua 站看「事件系统」时能跳到 Unity 站的对应页）

跨分类链接共 501 处，均使用相对路径，克隆后可直接跳转。
