# MOYUXUEXI — 游戏开发知识库

按技术栈分类的学习文档集合。全部内容为**纯静态 HTML**，克隆后用浏览器直接打开即可阅读，
不需要构建步骤，也不依赖外部 CDN。

**总量**：5 条路线，**154 页**，**242 个知识点**索引，**116 个代码样本**全部经过真实编译/运行验证。

---

## 分类结构

```
MOYUXUEXI/
├── index.html      总入口（路线选择）
├── unity/          C# + Unity 路线（30 页）
├── unreal/         C++ + Unreal 路线（29 页）
├── lua/            Lua 热更新路线（26 页）
├── algorithms/     游戏算法与系统设计（35 页）
├── backend/        游戏后端 + 全栈开发（34 页）
└── svn/            SVN 版本控制教程
```

每个路线目录里都有：

- `index.html` —— 路线总览
- `kp-index.html` —— 知识点索引（跨站共享 242 个知识点）
- `01-xxx.html` ~ —— 各章节
- `assets/` —— 该站的 CSS 与 JS

## 使用方式

**直接打开**：双击 `index.html`，或用浏览器打开任意站点的 `index.html`。

**快捷键**：

| 键 | 功能 |
|---|---|
| `/` | 聚焦搜索框 |
| `Esc` | 清除搜索 |
| 右上角 | 切换深色/浅色 |

**移动端**：自适应布局，侧栏可折叠。

## 技术栈

- 纯静态 HTML / CSS / JS，**零框架、零构建、零外部依赖**
- 各站独立 `assets/`
- 搜索、主题切换、阅读进度、知识点索引均为原生 JS
- 响应式布局
