高频参数速查

版本相关
  • -r 5　指定版本 5
  • -r 5:8　从 5 到 8
  • -c 8　等同于 -r 7:8，单次提交
  • -c -8　反向（撤销 r8）
  • -r HEAD　最新
  • -r BASE　工作副本基准
  • -r PREV　上一个版本
  • -r COMMITTED　上次提交的版本
  • URL@PEG　peg revision（路径在 PEG 版本下的样子）
  • {2026-10-01}:HEAD　按日期
递归与深度
  • -R / --recursive　递归
  • -N / --non-recursive　不递归
  • --depth empty　只有目录本身
  • --depth files　目录+文件
  • --depth immediates　+子目录（空）
  • --depth infinity　完全递归（默认）
  • --set-depth ARG　修改已检出目录的深度
认证与交互
  • --username U　用户名
  • --password P　密码
  • --no-auth-cache　不缓存凭据
  • --non-interactive　脚本必加，防止卡住等输入
  • --trust-server-cert　信任自签名证书
  • --config-dir DIR　用指定配置目录
输出控制
  • -v / --verbose　详细输出
  • -q / --quiet　精简输出
  • --xml　XML 格式（脚本解析用）
  • --summarize　只列出文件，不显示内容
  • --no-diff-added　新增文件不显示内容
  • --show-item ARG　只输出一个字段
  • --no-newline　不输出结尾换行
冲突处理（--accept 取值）
  • postpone　保留冲突，人工解决（默认）
  • working　接受当前工作副本内容
  • mine-full　整个文件用我的
  • theirs-full　整个文件用服务器的
  • mine-conflict　只在冲突块用我的
  • theirs-conflict　只在冲突块用服务器的
  • base　回到原始版本，丢弃双方改动
危险操作（用前想清楚）
  • --force　强制覆盖，会丢本地改动
  • --ignore-ancestry　忽略历史关系，直接覆盖内容
  • --no-ignore　连被忽略的文件也一起操作
  • --keep-local　删除版本控制但保留本地文件
  • svn revert -R .　撤销所有本地改动，不可逆
  • svnadmin rmtxns　删事务，可能丢数据

GUI 与命令行混用的一个注意事项

GUI 客户端和命令行操作的是同一个 .svn 工作副本，可以随意混用，不会冲突。 但要注意两点：

  • 不要在 GUI 操作进行中同时跑命令行—— 比如 TortoiseSVN 正在提交时，你在命令行执行 svn commit，会导致工作副本锁冲突（E155004）。 遇到就 svn cleanup。
  • GUI 的「刷新」不会自动—— 命令行改完后，TortoiseSVN 的图标覆盖可能还是旧状态，按 F5 或右键 → Refresh 才更新。

SVN 完全教程 · 从零到服务端运维

全部命令与输出基于 Subversion 1.14.5 (r1922182) 实测抓取。 教程中的仓库环境（svn-admin create 创建的 fsfs 格式仓库、 svnserve 协议服务、authz 权限矩阵、pre-commit / post-commit / pre-revprop-change 钩子、 dump / hotcopy 备份链路）均为真实搭建并逐步验证。

八个阶段回顾： 认识 SVN（1-3）→ 核心模型（4-5）→ 日常操作（6-9）→ 冲突处理（10）→ 分支与标签（11-14）→ 属性系统（15-16）→ 服务端部署（17-20）→ 运维与进阶（21-25）。
