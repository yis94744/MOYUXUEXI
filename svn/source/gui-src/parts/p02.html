2第一次检出：把代码拉到本地

「检出」（Checkout）是你和 SVN 的第一次接触： 把服务器上的项目完整复制一份到你电脑上，同时建立关联—— 以后你改了文件，SVN 知道该往哪个服务器传。

开始前你需要两样东西
  1. 仓库地址——形如 https://svn.公司.com/svn/项目名，找管理员要，或者在 VisualSVN 管理器里自己复制。
  2. 一个空的本地文件夹——用来放项目。建议路径短、不带中文和空格，比如 D:\work\MyProject。

操作步骤

CHECKOUT把代码拉到本地
在本地建一个空文件夹 比如在 D 盘建 D:\work\MyProject。 注意：这个文件夹可以是空的，但不要在里面放任何文件。
在这个文件夹上点右键 因为它是普通文件夹（还不是工作副本），菜单里只有少数几项。 如果嫌在文件夹内部右键不方便，也可以在文件夹的上一级、对着文件夹图标本身右键。
选择「SVN Checkout...」 注意是在菜单顶层，带 SVN 前缀那一项， 不用展开 TortoiseSVN 子菜单。
在弹出的对话框里填入仓库地址 见下方截图。绝大多数情况下，填完地址直接点 OK 就行， 其余选项保持默认。
如果提示输入账号密码，填上并勾选保存 勾选「保存密码」后，以后每次提交都不用再输。 账号同样是找管理员要。
等待进度条跑完 文件多的话会跑一会儿。完成后文件夹里就是完整的项目代码， 每个文件图标左下角会出现绿色对勾。

检出对话框逐项说明

◈Checkout 对话框（点击图可放大）Checkout Dialog
这个对话框只有几个地方需要你关心，从上到下：
界面项怎么填 / 什么意思
URL of repository
仓库地址		 唯一必填项。粘贴管理员给你的仓库地址，例如 https://svn.abc.com/svn/MyProject/trunk。 右边的下拉箭头保存你以前用过的地址，第二次检出直接选就行，不用重敲。
Checkout directory
检出到哪个目录		 通常已经自动填好了（就是你右键的那个文件夹）。 如果填的目录不存在，SVN 会帮你自动创建。
Checkout Depth
检出深度		 保持默认的 Fully recursive（完全递归），把整个项目都拉下来。 只有当项目特别大、你只想拉一部分时，才需要改这里。
Omit externals
忽略外部引用		 默认不要勾。只有当项目引用了别处的公共库、而你不想一起拉下来时才勾选。 这个选项平时用不到。
Revision
版本		 保持勾选 HEAD revision（最新版本）。 只有需要看历史某个时间点的代码时，才选下面的 Revision 并填版本号。
Choose items...
选择要检出的内容		 点开是个打勾列表，可以精细挑选要哪些文件夹。 平时用不到，大项目里配合稀疏检出才用。
OK / Cancel / Help 确认、取消、帮助。填完地址直接点 OK。

检出完成后会发生什么

◈检出进度对话框Progress
点 OK 后会弹出这个进度窗口，列出每个被拉下来的文件。 颜色不是随便标的：
紫色 = 新增到你本地（Add）　 蓝色 = 更新已有文件（Update）　 深红色 = 删除（Delete）　 黑色 = 其他

最后一行的统计信息——“Added: 12, Updated: 3”这种——可以按 Ctrl+C 复制下来发给同事。 窗口底部有 OK 按钮，点掉就完成了。
一个项目可以被检出几次？

随便几次。同一个仓库地址可以检出到多个不同文件夹， 它们互相独立。这在两个场景下很有用：

  • 同时看两个分支——一份检出主干、一份检出分支，并排对比。
  • 搞坏了重来——把出问题的文件夹删掉，重新检出一次，比修复快得多。

但要注意：不要把一个文件夹既当工作副本、又手动复制给别人， 复制出来的副本里的 .svn 信息会打架。给别人就是给仓库地址，让他自己检出。

别把整个仓库根目录检出来

如果管理员给你的是 https://svn.abc.com/svn/MyProject（不带 /trunk）， 检出来会包含 trunk、branches、tags 全部内容——所有分支和所有历史标签都拉一遍，可能几个 GB。

正确做法：检出时在地址后面补上 /trunk，只要主干：

  • 要主干 → .../MyProject/trunk
  • 要某个分支 → .../MyProject/branches/分支名
  • 要某个发布版 → .../MyProject/tags/v1.0.0
