TortoiseSVN + VisualSVN Server · 全鼠标操作

SVN 图形化实战
不敲一行命令

这是一份纯图形界面的 SVN 教程。所有操作都用右键菜单和对话框完成，每一步都配真实界面截图，说清「点哪个按钮、填什么、为什么」。

全教程按 6 个阶段、25 个小节展开。每个小节做成独立页面，可以单独打开阅读。主要面向 Windows 上的 TortoiseSVN 客户端 + VisualSVN Server 服务端这套标准组合。

#四条常见路径

路径 A：今天第一次用 SVN

从第 1 节顺序读。第 1 节认识两个软件，第 2 节把代码拉到本地，第 3 节认全右键菜单，第 4 节学会「改、更、提」这个日常循环。读完前四节就能正常干活了。

从第 1 节开始 →
路径 B：代码撞车了 / 出现冲突

直接看第 10 节和第 11 节。第 10 节讲冲突是怎么产生的、冲突文件里的标记怎么看、什么时候该找谁；第 11 节讲怎么用合并工具逐行解决，不用手工删标记。

打开冲突处理 →
路径 C：我要搭服务器 / 管权限

从第 19 节进入服务端部分。建仓库、加用户、配权限、做备份，全部在 VisualSVN Server Manager 里点鼠标完成，不用碰配置文件。
