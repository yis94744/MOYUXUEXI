关于内容可靠性

本教程的全部命令、参数与输出，都在 Windows 上搭建的 SVN 1.14.5 环境中逐条执行并抓取真实回显。写作过程中发现并修正了多处常见文档的错误说法（例如 status 实际有七列而非两列、svn:keywords 在 commit 时展开而非 update 时、svnserve.conf 行首空格会导致 E200002 解析失败）。凡是标「实测输出」的代码块，都可以直接复制运行。
