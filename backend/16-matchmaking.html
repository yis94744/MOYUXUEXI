    一、核心矛盾：快 vs 准 ★★

    匹配快的代价：对手水平差很大。匹配准的代价：等很久。解法是随时间放宽。

    using System;
using System.Collections.Generic;
using System.Linq;

namespace BackendSamples.Matchmaking
{
    // ============================================================
    // 1. 匹配的核心问题
    // ============================================================
    // 【矛盾】
    //   匹配快  -> 对手水平差很大 -> 体验差
    //   匹配准  -> 等很久 -> 玩家流失
    // 【解法】随时间放宽范围

    public class MatchPlayer
    {
        public long PlayerId;
        public string Name = "";
        public int Mmr;           // 匹配分
        public DateTime EnqueueAt;
        public int WaitSec => (int)(DateTime.UtcNow - EnqueueAt).TotalSeconds;

        public override string ToString() => $"{Name}(MMR={Mmr})";
    }

    // ============================================================
    // 2. 基础匹配：按 MMR 差
    // ============================================================

    public class Matchmaker
    {
        private readonly List<MatchPlayer> _pool = new();

        public void Enqueue(MatchPlayer p)
        {
            p.EnqueueAt = DateTime.UtcNow;
            _pool.Add(p);
            Console.WriteLine($"    {p.Name}(MMR={p.Mmr}) 进入匹配池，当前 {_pool.Count} 人");
        }

        public void Dequeue(long playerId) => _pool.RemoveAll(p => p.PlayerId == playerId);

        // 【核心】匹配范围随时间放宽
        public static int GetTolerance(int waitSec)
        {
            // 0-5 秒：±50 分
            // 5-15 秒：±100
            // 15-30 秒：±200
            // 30 秒+：不限
            if (waitSec < 5) return 50;
            if (waitSec < 15) return 100;
            if (waitSec < 30) return 200;
            return int.MaxValue;
        }

        // 尝试匹配一对
        public (MatchPlayer A, MatchPlayer B)? TryMatch()
        {
            if (_pool.Count < 2) return null;

            // 【关键】按等待时间优先（等得久的先匹配）
            var sorted = _pool.OrderByDescending(p => p.WaitSec).ToList();

            for (int i = 0; i < sorted.Count; i++)
            {
                var a = sorted[i];
                int tol = GetTolerance(a.WaitSec);

                for (int j = i + 1; j < sorted.Count; j++)
                {
                    var b = sorted[j];
                    if (Math.Abs(a.Mmr - b.Mmr) <= tol)
                    {
                        _pool.Remove(a);
                        _pool.Remove(b);
                        return (a, b);
                    }
                }
            }

            return null;
        }

        public int PoolCount => _pool.Count;
        public IReadOnlyList<MatchPlayer> Pool => _pool;
    }

    // ============================================================
    // 3. 分段匹配：大规模下的必需
    // ============================================================
    // 【问题】10 万人在池里，两两比较是 O(n²) = 100 亿次
    // 【解法】按 MMR 分段（bucket），只在相邻桶里找

    public class SegmentedMatchmaker
    {
        private const int BucketSize = 100;   // 每 100 分一个桶
        private readonly Dictionary<int, List<MatchPlayer>> _buckets = new();

        public void Enqueue(MatchPlayer p)
        {
            p.EnqueueAt = DateTime.UtcNow;
            int bucket = p.Mmr / BucketSize;
            if (!_buckets.TryGetValue(bucket, out var list))
            {
                list = new List<MatchPlayer>();
                _buckets[bucket] = list;
            }
            list.Add(p);
        }

        // 【关键】只在「自己桶 + 相邻桶」里找
        public (MatchPlayer A, MatchPlayer B)? TryMatch(int bucketIdx)
        {
            // 先看自己桶
            var result = TryMatchIn(bucketIdx);
            if (result != null) return result;

            // 再看相邻桶（放宽范围）
            result = TryMatchIn(bucketIdx - 1);
            if (result != null) return result;

            return TryMatchIn(bucketIdx + 1);
        }

        private (MatchPlayer, MatchPlayer)? TryMatchIn(int bucket)
        {
            if (!_buckets.TryGetValue(bucket, out var list) || list.Count < 2) return null;

            var a = list[0];
            var b = list[1];
            list.RemoveAt(1);
            list.RemoveAt(0);
            if (list.Count == 0) _buckets.Remove(bucket);
            return (a, b);
        }

        public int TotalInPool => _buckets.Values.Sum(l => l.Count);
        public int BucketCount => _buckets.Count;
    }

    // ============================================================
    // 4. Elo 评分：怎么算「该赢多少分」
    // ============================================================
    // 【核心思想】赢强手加分多，赢弱手加分少
    //   胜率 = 1 / (1 + 10^((对手分 - 自己分)/400))

    public static class EloRating
    {
        private const int K = 32;   // 影响因子（越大变化越快）

        // 期望胜率
        public static double ExpectedScore(int myMmr, int oppMmr)
        {
            return 1.0 / (1.0 + Math.Pow(10, (oppMmr - myMmr) / 400.0));
        }

        // 计算新分数
        public static (int NewMmr, int Delta) Update(int myMmr, int oppMmr, bool won)
        {
            double expected = ExpectedScore(myMmr, oppMmr);
            double actual = won ? 1.0 : 0.0;
            int delta = (int)(K * (actual - expected));
            return (myMmr + delta, delta);
        }
    }

    // ============================================================
    // 5. 组队匹配
    // ============================================================
    // 【问题】三人组队，怎么和单人匹配？
    //   方案1：队伍整体算一个 MMR（取平均或最高）
    //   方案2：只匹配相同队伍人数

    public class Team
    {
        public List<MatchPlayer> Members = new();

        // 【常用】取队伍最高 MMR（防止带小号）
        public int TeamMmr => Members.Count > 0 ? Members.Max(m => m.Mmr) : 0;

        // 或者取平均
        public int AverageMmr => Members.Count > 0 ? (int)Members.Average(m => m.Mmr) : 0;

        public override string ToString() =>
            $"队伍[{string.Join(", ", Members.Select(m => m.Name))}] MMR={TeamMmr}";
    }

    // ============================================================
    // 演示
    // ============================================================
    public static class Demo
    {
        public static void Run()
        {
            Console.WriteLine("=== 1. 匹配范围随时间放宽 ===");
            foreach (int sec in new[] { 0, 5, 15, 30, 60 })
            {
                int tol = Matchmaker.GetTolerance(sec);
                var tolStr = tol == int.MaxValue ? "不限" : "±" + tol;
                Console.WriteLine($"    等待 {sec,2} 秒 -> 可接受 MMR 差 {tolStr}");
            }
            Console.WriteLine();
            Console.WriteLine("  【关键】这是「体验 vs 速度」的平衡");
            Console.WriteLine("          不给放宽 -> 高分玩家长时间匹配不到");

            Console.WriteLine();
            Console.WriteLine("=== 2. 基础匹配 ===");
            var mm = new Matchmaker();
            var now = DateTime.UtcNow;

            mm.Enqueue(new MatchPlayer { PlayerId = 1, Name = "新手A", Mmr = 1000 });
            mm.Enqueue(new MatchPlayer { PlayerId = 2, Name = "新手B", Mmr = 1030 });
            mm.Enqueue(new MatchPlayer { PlayerId = 3, Name = "高手", Mmr = 2000 });

            var m1 = mm.TryMatch();
            Console.WriteLine($"  【匹配结果】{(m1 != null ? $"{m1.Value.A.Name} vs {m1.Value.B.Name}" : "无匹配")}");
            Console.WriteLine($"    MMR 差: {(m1 != null ? Math.Abs(m1.Value.A.Mmr - m1.Value.B.Mmr) : 0)}（在 ±50 内）");

            Console.WriteLine();
            Console.WriteLine("  剩下的高手 MMR=2000 匹配不到:");
            var m2 = mm.TryMatch();
            Console.WriteLine($"    【匹配结果】{(m2 == null ? "无匹配（池里只剩1人）" : "匹配成功")}");

            Console.WriteLine();
            Console.WriteLine("  加入一个 MMR=2100 的玩家，模拟等待后放宽:");
            mm.Enqueue(new MatchPlayer { PlayerId = 4, Name = "高手2", Mmr = 2100 });

            // 模拟等了 20 秒（放宽到 ±200）
            foreach (var p in mm.Pool) p.EnqueueAt = now.AddSeconds(-20);
            var m3 = mm.TryMatch();
            Console.WriteLine($"    【匹配结果】{(m3 != null ? $"{m3.Value.A.Name} vs {m3.Value.B.Name}" : "无匹配")}");

            Console.WriteLine();
            Console.WriteLine("=== 3. 分段匹配（大规模）===");
            var seg = new SegmentedMatchmaker();
            var rnd = new Random(42);

            // 1000 人随机 MMR
            for (int i = 1; i <= 1000; i++)
            {
                seg.Enqueue(new MatchPlayer { PlayerId = i, Name = $"P{i}", Mmr = rnd.Next(800, 2200) });
            }
            Console.WriteLine($"  1000 人入池，分成 {seg.BucketCount} 个桶（每桶 100 分）");

            int matched = 0;
            for (int round = 0; round < 300; round++)
            {
                if (seg.TryMatch(rnd.Next(8, 22)) != null) matched++;
            }
            Console.WriteLine($"  匹配 {matched} 场，池里还剩 {seg.TotalInPool} 人");
            Console.WriteLine();
            Console.WriteLine("  【为什么分段】");
            Console.WriteLine("    1000 人两两比较 = 50 万次");
            Console.WriteLine("    分段后只比相邻桶 = 几千次");

            Console.WriteLine();
            Console.WriteLine("=== 4. Elo 评分 ===");
            var matchups = new[]
            {
                (me: 1500, opp: 1500, won: true,  desc: "同分赢了"),
                (me: 1500, opp: 1500, won: false, desc: "同分输了"),
                (me: 1500, opp: 2000, won: true,  desc: "赢高手"),
                (me: 1500, opp: 1000, won: true,  desc: "赢弱手"),
                (me: 1500, opp: 2000, won: false, desc: "输给高手"),
            };

            Console.WriteLine($"    {"场景",-14} {"期望胜率",-10} 分数变化");
            foreach (var m in matchups)
            {
                double exp = EloRating.ExpectedScore(m.me, m.opp);
                var (newMmr, delta) = EloRating.Update(m.me, m.opp, m.won);
                Console.WriteLine($"    {m.desc,-14} {exp*100,6:F1}%    {delta:+0;-0} -> {newMmr}");
            }

            Console.WriteLine();
            Console.WriteLine("  【关键观察】");
            Console.WriteLine("    · 赢高手 +19（期望胜率只有 6%）");
            Console.WriteLine("    · 赢弱手 +1（期望胜率 94%，赢了是应该的）");
            Console.WriteLine("    · 这保证分数能反映真实水平");

            Console.WriteLine();
            Console.WriteLine("=== 5. 组队匹配 ===");
            var team1 = new Team
            {
                Members = new()
                {
                    new MatchPlayer { PlayerId = 10, Name = "A", Mmr = 1200 },
                    new MatchPlayer { PlayerId = 11, Name = "B", Mmr = 1400 },
                    new MatchPlayer { PlayerId = 12, Name = "C", Mmr = 1600 },
                }
            };
            Console.WriteLine($"  {team1}");
            Console.WriteLine($"    最高 MMR: {team1.TeamMmr}（防带小号）");
            Console.WriteLine($"    平均 MMR: {team1.AverageMmr}");
            Console.WriteLine();
            Console.WriteLine("  【选哪个】");
            Console.WriteLine("    · 取最高 -> 防止高手带小号虐菜");
            Console.WriteLine("    · 取平均 -> 更公平但容易滥用");
            Console.WriteLine("    · 实战多用「最高 + 人数加成」");
        }
    }
}

public class Program
{
    public static void Main() => BackendSamples.Matchmaking.Demo.Run();
}
    等待时间可接受 MMR 差玩家感受
    0~5 秒±50势均力敌
    5~15 秒±100能接受
    15~30 秒±200开始有压力
    30 秒+不限能玩就行

    二、分段匹配：大规模下的必需 ★★

    O(n²) 会炸 问题：10 万人在匹配池里
    · 两两比较 → 100 亿次
    · 每秒跑一次 → 服务器直接死

    解法：按 MMR 分段（bucket）
    · 每 100 分一个桶
    · 只在「自己桶 + 相邻桶」里找
    · 比较次数从 100 亿降到几千

    本页实测：
    1000 人入池，分成 14 个桶（每桶 100 分）
    匹配 300 场，池里还剩 400 人

    注意：分桶后要处理「桶里人数不均」——高分玩家可能一个人一个桶，需要放宽到相邻桶。

    三、Elo 评分：赢强手加分多 ★★

    公式与直觉 期望胜率：
    1 / (1 + 10^((对手分 - 自己分) / 400))

    本页实测的五种情况：
    场景期望胜率分数变化
    同分赢了50%+16
    赢高手（1500 vs 2000）5.3%+30
    赢弱手（1500 vs 1000）94.7%+1
    直觉：
    · 赢强手 → 意料之外，加分多
    · 赢弱手 → 理所当然，加分少
    · 这样分数才能反映真实水平

    （本页 K = 32；期望胜率 5.3% 时 +30，94.7% 时 +1——赢弱手几乎不加分）

    K 值：决定变化速度
    · 新手用大 K（快速定位）
    · 老玩家用小 K（稳定）

    四、组队匹配：取最高还是平均

    取平均会被滥用 场景：一个高手（MMR 2000）带一个新手（MMR 500）
    · 取平均 = 1250 → 匹配到中等对手
    · 结果：高手在虐菜

    本页的做法：取最高
    TeamMmr = Members.Max(m => m.Mmr)
    → 2000 → 匹配到同样是高手带队的队伍

    实战折中：取最高 + 人数加成
    · 3 人队 vs 3 人队，权重相同
    · 但 3 人队匹配到 1 人队要额外加成

    还要考虑：队伍人数是否允许不同（大多数游戏要求人数相同）。
