一、HTTP 状态码

码含义什么时候用
200成功正常返回
201已创建POST 创建资源
204成功无内容DELETE
400参数错误客户端问题
401未认证Token 失效
403无权限已登录但没权限
404不存在资源找不到
409冲突重复提交
429太频繁限流
500服务器错误代码 bug
503不可用熔断/维护
业务失败用 200 还是 4xx 推荐：
· 协议层错误（参数、认证）→ 4xx
· 业务失败（金币不足）→ 200 + code

因为：「金币不足」不是接口出错，是正常业务结果。
关键不是选哪个，而是团队统一。

段含义客户端行为

四、EF Core 查询要点

场景写法
避免 N+1.Include(x => x.Items)
只读查询.AsNoTracking()
分页.Skip(n).Take(m)
条件更新ExecuteUpdate
批量删除ExecuteDelete
事务BeginTransaction()
两个必知的坑 ① AsNoTracking 只读查询必加
不加会追踪每个实体 → 内存暴涨、变慢。

② 循环里访问导航属性 = N+1
foreach (var p in players) { p.Items }
每次都会查一次数据库 → 用 Include 或一次性取回。
