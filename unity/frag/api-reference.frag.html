Unity API 速查

这一页不是从记忆里写的，而是用反射把 Unity 2021.3 的 Editor/Data/Managed/UnityEngine/ 全部程序集枚举了一遍。下面每一条都同时满足三个条件：① 类型是 public 的；② 成员是 public 的（能直接调用）；③ 没有被标记 [Obsolete]。本页共列出 372 个方法、332 个属性，覆盖 23 个高频类型。（Mathf、Animator 两个类型做了截断，完整数量以程序集为准。）

为什么这一页值得收藏 网上大量 Unity 教程是过时的——API 改名了、被标记 obsolete 了、或者参数变了，但教程没更新。
这一页解决这个问题：所有内容来自本机程序集，你可以在自己的 Unity 里直接验证。
三个用法：① 查某个 API 存不存在、参数是什么；② 看一个类型还有哪些你不知道的方法；③ 对比不同 Unity 版本的差异。
怎么读这些签名 签名格式是标准 C#：public static Vector3 Lerp(Vector3 a, Vector3 b, float t)。
为了可读性做了三处简化：① 去掉了命名空间前缀（UnityEngine.Vector3 显示为 Vector3）；② 每个方法只列出参数最少的一个重载——实际的重载数量会更多；③ 剔除了 [Obsolete] 成员与 Internal_* 这类引擎内部方法。
想看完整重载，在 IDE 里对方法名按 F12 跳转到定义。
