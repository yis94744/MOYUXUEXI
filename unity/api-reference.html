    Unity API 速查

    这一页不是从记忆里写的，而是从 Unity 2021.3 与 2022.3 的运行时程序集里直接提取的真实签名：共 8998 条，覆盖 110 个类型。这里出现的每个方法都真实存在，参数类型也准确。

    为什么这一页值得收藏 网上大量 Unity 教程是过时的——API 改名了、被标记 obsolete 了、或者参数变了，但教程没更新。
    这一页解决这个问题：所有内容来自本机程序集，你可以在自己的 Unity 里直接验证。
    三个用法：① 查某个 API 存不存在、参数是什么；② 看一个类型还有哪些你不知道的方法；③ 对比不同 Unity 版本的差异。
    怎么读这些签名 签名格式是标准 C#：public static Vector3 Lerp(Vector3 a, Vector3 b, float t)。
    为了可读性做了两处简化：① 去掉了命名空间前缀（UnityEngine.Vector3 显示为 Vector3）；② 每个方法只列出参数最少的一个重载——实际的重载数量会更多。
    想看完整重载，在 IDE 里对方法名按 F12 跳转到定义。
