    一、五步排查流程

    UE 的性能排查有固定的工具和流程。不会用 Insights，就等于蒙眼优化。

    步骤做什么工具
    1. 确认现象卡顿？掉帧？加载慢？Play in Editor vs 打包版
    2. 定位类型CPU / GPU / 内存 / 加载Unreal Insights
    3. 缩小范围哪个系统？哪个函数？stat 命令
    4. 修改验证只改一处，立即测对比数据
    5. 回归测试确认没引入新问题全流程跑
    最重要的提醒：PIE 数据不可信 Unreal 的 Play in Editor（PIE）性能数据不能用于优化决策。

    原因：
    · 编辑器本身有开销
    · PIE 有额外的代理层
    · Debug 配置未开优化（慢几倍）
    · 很多问题只在 Shipping 配置下暴露

    正确做法：
    ① 用 Development 配置打包测试（不是 PIE）
    ② 最终用 Shipping 配置验证
    ③ 对比 PIE 和打包版的差异，PIE 只用来"快速看有没有大问题"

    典型陷阱：PIE 里跑 60 帧，打包后只有 30 帧——因为 PIE 可能跳过了某些检查，或者打包后启用了更严格的渲染路径。
    Unreal Insights：最重要的工具 Insights 是 UE 的性能分析工具——类似 Unity 的 Profiler，但更强。

    能看什么：
    · CPU 时间线——每个线程在做什么
    · 帧的详细分解
    · GPU 时间
    · 内存分配
    · 加载时间

    启动方式：
    · 启动 Insights 应用
    · 游戏里输入 Trace.Start
    · 或启动参数加 -tracehost=localhost

    最实用的功能：看"哪个函数占了最多帧时间"——直接定位到具体的代码。

    二、常用 stat 命令速查

    命令看什么什么时候用
    stat fps帧率基础
    stat unitFrame/Game/Draw/GPU 分解最常用
    stat game游戏逻辑耗时CPU 瓶颈
    stat gpuGPU 各阶段耗时GPU 瓶颈
    stat rhiDraw Call 数渲染瓶颈
    stat memory内存占用内存问题
    stat particles粒子数特效瓶颈
    stat physics物理耗时物理瓶颈
    stat anim动画耗时动画瓶颈
    stat uiwidgetsUI 耗时UI 瓶颈
    stat unit 怎么读 ★★ stat unit 显示四个数字：
    Frame   16.7 ms
    Game    2.1 ms
    Draw    3.5 ms
    GPU     14.2 ms

    怎么判断瓶颈：
    · Frame 是总时间，其他三个是各部分的耗时
    · 哪个数字接近 Frame，哪个就是瓶颈
    · 上面的例子：GPU 14.2 接近 Frame 16.7 → GPU 瓶颈

    如果 Game 是瓶颈：看 stat game 进一步细分。
    如果 GPU 是瓶颈：看 stat gpu 找具体的渲染阶段。

    这是最实用的性能排查方法——比开 Insights 更快。

    三、优化优先级

    优先级优化项典型收益难度
    1关掉不必要的 Tick大低
    2UI 加 Invalidation Box大低
    3减少 Draw Call（合批）大中
    4降低特效/阴影质量大低
    5Nanite/Lumen 按需开关大中
    6对象池中中
    7LOD / 剔除中中
    8C++ 替换蓝图热路径看场景中
    9并行化（ParallelFor）看场景高
    为什么把"关 Tick"排第一 因为收益大、成本低、风险小。

    UE 项目的 Tick 灾难：
    · 每个 Actor 默认可能开 Tick
    · 1000 个 Actor 每帧 Tick = 明显开销
    · 很多 Tick 完全可以关掉（静态物体、不需要每帧更新的）

    怎么优化：
    ① PrimaryActorTick.bCanEverTick = false;（不需要就关）
    ② 降低 Tick 频率：PrimaryActorTick.TickInterval = 0.1f;
    ③ 用定时器代替 Tick（只在需要时执行）
    ④ 用事件驱动代替轮询

    检查方法：stat game 看 Game 时间 → 如果高，用 Insights 看是哪些 Actor 在 Tick。
