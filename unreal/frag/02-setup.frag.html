一、安装清单

组件版本建议体积备注
Visual Studio 202217.x Community~10 GB必须装 C++ 工作负载
UE5 引擎5.3 / 5.4~40 GB用 Epic Launcher 装
引擎源码（可选）GitHub 版本~100 GB深入引擎时再装
.NET SDK6.0+~500 MBUE 构建工具依赖
Rider（可选）最新版~2 GB比 VS 好用（推荐）
四个必踩的坑 ① 没装 VS 的 C++ 工作负载
只装 VS 不够——必须勾选"使用 C++ 的桌面开发"。
症状：Unable to find Visual Studio installation

② 没装 Windows SDK
属于 C++ 工作负载的一部分，但有时要手动勾。

③ 没装 .NET SDK
UE 的构建工具（UnrealBuildTool）是 C# 写的。
症状：UnrealBuildTool 无法运行

④ 项目路径含中文或空格
这是最常见的坑。
UE 对路径很敏感，中文路径会导致各种诡异的编译错误。
规则：路径全英文、无空格、不要太深（例如 D:\UEProjects\MyGame）。
推荐的开发环境组合 编辑器：Rider for Unreal Engine（比 VS 好用很多）
· 更好的代码补全
· 能识别 UE 的宏
· 重构功能强

如果你只能用 VS：
· 装 Visual Assist 插件（付费但值得）
· 或者用 VS Code + C++ 插件（但要配 compile_commands.json）

为什么编辑器很重要：Unreal 的代码量很大，没有好的跳转和补全，开发效率会大幅下降。

二、创建第一个项目

创建流程 ① 打开 Epic Launcher，启动 UE5
② 选择"游戏" → 选模板
· Blank——空的，从零开始（推荐学习用）
· Third Person——第三人称模板（有现成角色）
③ 关键设置
· Blueprint 或 C++？→选 C++（会生成 C++ 项目结构）
· Starter Content→建议勾选（有一些免费素材）
· 项目位置→全英文路径
④ 点击创建，等待编译
第一次会编译引擎相关的东西，可能需要 10~30 分钟。
⑤ 编译完成后会打开编辑器

如果编译失败：优先检查上面那四个坑。

本章动手任务

本章过关标准：
① VS 装了 C++ 工作负载；
② 成功创建并编译了一个 C++ 项目；
③ 项目路径全英文；
④ 能修改 C++ 代码并重新编译；
⑤ 知道四个常见的安装坑。

这一页的标准很硬——**编译不通过就不要往下走**。Unreal 的坑大多在前面。
