3安装与环境准备

Windows：三种安装方式

方式一：SlikSVN（只装命令行）

最纯净，只有 svn 和 svnadmin 命令，安装包约 10MB。

适合：服务器、CI 机器、只要命令行的人。

sliksvn.com/download

方式二：VisualSVN Server

一站式服务端，自带图形管理器 + Apache，Web 界面可视化管理仓库与用户。

适合：要搭服务器的 Windows 团队（推荐）。

visualsvn.com/server

方式三：TortoiseSVN（图形外壳）

集成到资源管理器右键菜单，不提供命令行工具（需勾选 command line client tools）。

适合：不习惯命令行的 GUI 用户。

tortoisesvn.net

TortoiseSVN 安装时的一个坑

安装向导默认不勾选「command line client tools」。 如果你既想要右键菜单、又想在脚本里用 svn 命令，安装时必须手动选上这一项， 否则会在命令行里看到 'svn' 不是内部或外部命令。

Linux：包管理器一行搞定

bash安装客户端 + 服务端
# Debian / Ubuntu
sudo apt update && sudo apt install -y subversion

# RHEL / CentOS / Rocky
sudo dnf install -y subversion

# 顺便装上命令行补全工具（强烈推荐，能补全子命令和参数）
sudo apt install -y subversion-tools
# 或
sudo dnf install -y subversion-tools

# 验证
svn --version --quiet          # 只输出版本号，脚本里好用
svn --version -q               # 等价简写
which svn svnadmin svnserve svnlook

macOS：Homebrew

bashmacOS 安装
# macOS 自带的是很老的 1.7/1.8，务必用 brew 装新的
brew install subversion

# 确认用到的是 brew 版本而不是系统自带
which svn
# 期望输出：/opt/homebrew/bin/svn  （而不是 /usr/bin/svn）

# 如果还是系统的，把它加入 PATH 最前面
export PATH="/opt/homebrew/opt/subversion/bin:$PATH"

验证安装：一个自检脚本

装完别急着往下走，先跑这个自检——它能一次性告诉你客户端、服务端工具、协议支持是否齐全。

bashcheck-svn.sh　自检脚本
#!/usr/bin/env bash
# SVN 环境自检：确认客户端、服务端工具链、协议模块是否齐全
set -u

echo "===== 1. 四个核心可执行文件 ====="
for bin in svn svnadmin svnserve svnlook; do
  if command -v "$bin" >/dev/null 2>&1; then
    printf "  [OK]   %-10s %s\n" "$bin" "$(command -v "$bin")"
  else
    printf "  [MISS] %-10s 未安装\n" "$bin"
  fi
done

echo
echo "===== 2. 客户端版本 ====="
svn --version --quiet

echo
echo "===== 3. 仓库访问模块（协议支持）====="
svn --version | grep -E '^\* ra_' || echo "  (未检测到 ra_ 模块，异常)"

echo
echo "===== 4. 服务端工具版本 ====="
svnadmin --version --quiet
svnserve --version --quiet
svnlook --version --quiet

echo
echo "===== 5. 可用子命令总数 ====="
printf "  svn      : %s 个\n" "$(svn help | grep -cE '^   [a-z]')"
printf "  svnadmin : %s 个\n" "$(svnadmin help | grep -cE '^   [a-z]')"

echo
echo "自检完成。"

Windows 用户注意路径写法

本教程的命令在 Windows PowerShell / CMD 与 Linux bash 下完全通用， 唯一要改的是本地路径：Windows 是 E:\repo，Linux 是 /var/svn/repo。 而 URL 里的本地路径必须写成 file:///E:/repo 这种形式（三斜杠 + 盘符 + 正斜杠）。
