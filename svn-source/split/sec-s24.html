客户端命令

命令作用最常用选项
取仓库 —— 把代码弄到本地
checkout 把仓库内容检出成工作副本 -r REV 检出指定版本　--depth ARG 稀疏检出　--username/-password
export 导出干净副本（无 .svn） -r REV　--force 覆盖已有　--ignore-externals
list (ls) 列出仓库目录（不用检出） -v 带版本作者　-R 递归　-r REV
cat 看仓库里某个文件的内容 -r REV　URL@PEG 语法
import 把现成目录导入仓库（不留工作副本） -m MSG 必填　--no-ignore
改内容 —— 日常开发主力
update 从仓库拉取最新改动到工作副本 -r REV　--accept ARG 冲突策略　--non-interactive　--set-depth
commit 把工作副本改动提交到仓库 -m MSG　--file F　--changelist ARG　-N 非递归
add 把新文件纳入版本控制 --force　--no-ignore　--depth ARG　--auto-props
delete (rm) 从版本控制中删除 --force　--keep-local 保留本地文件
copy (cp) 复制（建分支/标签的核心） -r REV 从历史版本复制　--parents 自动建父目录
move (mv) 移动/重命名（保留历史） --force　--parents
revert 撤销本地未提交的改动 -R 递归　--depth ARG　--changelist ARG
mkdir 建目录（本地或服务端） -m MSG URL 形式必填　--parents
resolve 标记冲突已解决 --accept working|mine-full|theirs-full|base|mine-conflict|theirs-conflict　-R
看状态 —— 提交前的自查
status (st) 查看工作副本状态（最重要） -u 对比服务器　-v 带版本号　-q 精简　--no-ignore 显示被忽略的
diff (di) 比较差异 -r N:M 版本区间　-c N 单次提交　--summarize 只列文件　--git　--file F
log 查看提交历史 -l N 条数　-r N:M　-v 带路径　-g 合并图谱　-q 精简　--search　--xml
info 查看工作副本/URL 的详细信息 --show-item ARG 只输出一个字段　--xml　-R
blame (praise) 逐行显示最后修改者 -r N:M　-v 带日期　-x -w 忽略空白　--xml
分支合并 —— 多人协作核心
switch (sw) 切换工作副本对应的 URL（换分支） --relocate OLD NEW　--ignore-ancestry　--depth ARG　--accept ARG
merge 合并分支改动 -c N / -c -N 反向　-r N:M　--dry-run　--record-only　--reintegrate　--ignore-ancestry
patch 应用 unidiff 格式的补丁 --dry-run　--reverse-diff　--strip N
属性 —— 解锁隐藏能力
propset (pset) 设置属性 --file F 从文件读多行值　-R 递归　--revprop -r N 改版本属性
propget (pget) 读取属性值 -R　--revprop -r N　--strict
proplist (plist) 列出所有属性名 -v 带值　-R 递归
propdel (pdel) 删除属性 -R　--revprop -r N
propedit (pedit) 用编辑器编辑属性（多行值必备） --editor-cmd CMD　--revprop -r N
锁与清理 —— 二进制与救急
lock 加锁（配合 svn:needs-lock） -m MSG 加锁说明　--force 强制抢锁
unlock 解锁 --force 强制解他人锁　-R
cleanup 清理工作副本的锁和中间状态 --remove-unversioned 删未跟踪文件　--remove-ignored　--vacuum-pristines
changelist (cl) 变更列表分组 --remove　--recursive　--depth ARG
upgrade 升级旧格式工作副本 --quiet

服务端命令

命令作用关键参数与说明
svnadmin —— 仓库管理（最常和 svnadmin 打交道）
svnadmin create 创建仓库 --fs-type fsfs（默认，别用 bdb）　--compatible-version 1.8
svnadmin dump 导出仓库为 dump 文件（逻辑备份） --file F ★避免 PowerShell 重定向　-r N:M　--incremental　--deltas　--quiet
svnadmin load 从 dump 文件恢复 --file F　--ignore-uuid　--force-uuid　--revision N:M
svnadmin hotcopy 完整热备（复制整个仓库） --clean-logs　—— 速度快，但格式绑定版本
svnadmin verify 校验仓库完整性 -r N:M　—— 定期跑，提前发现磁盘问题
svnadmin pack 合并小版本文件（减少文件数） FSFS 专用，大仓库定期执行
svnadmin freeze 冻结仓库执行外部命令（打包/rsync） svnadmin freeze REPO -- tar czf out.tgz
svnadmin recover 灾难恢复 需停服务；BDB 时代的常用命令，FSFS 下很少用
svnadmin upgrade 升级仓库格式 升级 SVN 版本后执行
svnadmin info 查看仓库元信息 UUID / Revisions / Format / FSFS 信息
svnadmin lstxns 列出未完成事务 配合 rmtxns 清理钩子崩溃留下的垃圾
svnadmin lslocks 列出仓库中所有锁 配合 rmlocks 清理
svnadmin setlog 修改提交日志 需要 pre-revprop-change 钩子支持
svnadmin setuuid 修改仓库 UUID 克隆仓库后必须改，否则两个库互相冲突
svnadmin rev-size 查看各版本占用空间 找「哪个提交引入了大文件」时很有用
svnserve —— 服务进程
svnserve -d 守护进程模式 -r /var/svn 仓库根目录（必填）　--listen-port 3690　--listen-host 0.0.0.0　--log-file F　--pid-file F
svnserve -i inetd 模式（由 inetd/xinetd 拉起） 老式部署，现在少用
svnserve -t 隧道模式（配合 svn+ssh://） 由 SSH 调用
svnserve -X Windows 服务模式 sc create 注册时用
--foreground 前台运行（调试用） 首次部署强烈建议这样启动，能立刻看到报错
svnlook / 其他工具 —— 只读检查与服务端运维
svnlook log 查看提交日志 -r REV 看已提交的　-t TXN 看事务中的（钩子里必用）
svnlook changed 查看某版本改了哪些路径 -r REV / -t TXN　--copy-info
svnlook author / date 查看提交者 / 时间 post-commit 钩子里做通知时必用
svnlook youngest 查看仓库最新版本号 脚本里判断「需不需要备份」常用
svnlook filesize 查看文件大小 pre-commit 里拦截大文件用
svnlook diff 查看某版本的差异 钩子里发详细通知邮件时用
svnlook tree 查看仓库目录树 -r REV　--full-paths
svnlook youngest/verify 仓库健康检查 只读，不影响运行中的仓库
svndumpfilter 过滤 dump 文件（去掉/只保留某些路径） include /exclude PATH　--drop-empty-revs　--renumber-revs
svnrdump 远程 dump/load（无需登录服务器） dump URL -r N:M --file F　load URL --file F
svnauthz 校验/查询 authz 权限 svnauthz access --username U --path /p AUTHZ
svnmucc 单次提交执行多个操作（不需要工作副本） put / cp / mv / rm / mkdir 组合，一条命令一次提交

高频参数速查

版本相关
  • -r 5　指定版本 5
  • -r 5:8　从 5 到 8
  • -c 8　等同于 -r 7:8，单次提交
  • -c -8　反向（撤销 r8）
  • -r HEAD　最新
  • -r BASE　工作副本基准
  • -r PREV　上一个版本
  • -r COMMITTED　上次提交的版本
  • URL@PEG　peg revision（路径在 PEG 版本下的样子）
  • {2026-10-01}:HEAD　按日期
递归与深度
  • -R / --recursive　递归
  • -N / --non-recursive　不递归
  • --depth empty　只有目录本身
  • --depth files　目录+文件
  • --depth immediates　+子目录（空）
  • --depth infinity　完全递归（默认）
  • --set-depth ARG　修改已检出目录的深度
认证与交互
  • --username U　用户名
  • --password P　密码
  • --no-auth-cache　不缓存凭据
  • --non-interactive　脚本必加，防止卡住等输入
  • --trust-server-cert　信任自签名证书
  • --config-dir DIR　用指定配置目录
输出控制
  • -v / --verbose　详细输出
  • -q / --quiet　精简输出
  • --xml　XML 格式（脚本解析用）
  • --summarize　只列出文件，不显示内容
  • --no-diff-added　新增文件不显示内容
  • --show-item ARG　只输出一个字段
  • --no-newline　不输出结尾换行
冲突处理（--accept 取值）
  • postpone　保留冲突，人工解决（默认）
  • working　接受当前工作副本内容
  • mine-full　整个文件用我的
  • theirs-full　整个文件用服务器的
  • mine-conflict　只在冲突块用我的
  • theirs-conflict　只在冲突块用服务器的
  • base　回到原始版本，丢弃双方改动
危险操作（用前想清楚）
  • --force　强制覆盖，会丢本地改动
  • --ignore-ancestry　忽略历史关系，直接覆盖内容
  • --no-ignore　连被忽略的文件也一起操作
  • --keep-local　删除版本控制但保留本地文件
  • svn revert -R .　撤销所有本地改动，不可逆
  • svnadmin rmtxns　删事务，可能丢数据
